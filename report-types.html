Available Report Types
All reports are generated through the Request Center on the Reports module. Select a report type, configure parameters, choose an output format and submit — the request is queued and the output captured as an immutable snapshot.
Reports marked Financial require the Financial Reports feature to be enabled for your company by the Master Administrator (Company Features → Financial Reports). If disabled, those report types will appear grayed out in the Request Center.
Procurement
2 reports
Purchase Order Report
Full listing of purchase orders with all line items, quantities, unit costs, subtotals, supplier details, payment terms and current approval status. Supports filtering by a single PO number or a range (PO From → PO To). Leave both parameters blank to include all POs.
Parameters
PO Number From
e.g. PO-2024-001  ·  blank = all
PO Number To
same as From = single PO
Output Format
PDF · Excel · HTML
Receiving Transaction Summary
Itemised goods receipt log per purchase order. Lists quantities ordered vs. quantities received, variance amounts, receipt dates, receiving party and linked PO references. Filter by date range and optionally by a specific PO number.
Parameters
Date From
receipt date range start
Date To
receipt date range end
PO Number
blank = all POs
Output Format
PDF · Excel · HTML

Inventory Report
Complete product catalogue snapshot with current stock levels, reorder thresholds, category classification, unit pricing, supplier linkage, lead times and MOQ. Optionally filter by category name and/or stock level status (all, low stock only, out of stock only).
Parameters
Category
e.g. Electronics  ·  blank = all
Stock Status
All · Low Stock · Out of Stock
Output Format
PDF · Excel · HTML

Supplier Report
Master supplier directory including full contact details, payment terms, default shipment mode, preferred currency, TIN/tax identification, compliance status and registration date. Filter by supplier code (exact or prefix) and/or status.
Parameters
Supplier Code
e.g. SUP-001  ·  blank = all
Status
All · Active · Inactive · Blacklisted
Output Format
PDF · Excel · HTML
Supplier Spend Analysis Financial
Aggregated spend per supplier over a configurable period — total PO value issued, number of orders placed and average order size. Useful for vendor performance review and contract negotiations.
Parameters
Supplier Filter
supplier name/code  ·  blank = all
Period
All Time · This Month · Last Month · This Quarter · This Year
Output Format
PDF · Excel · HTML

Budget Report Financial
Department and fiscal period budget utilisation compared against approved PO spend and committed amounts. Highlights over-budget and under-utilised cost centres per quarter or fiscal period.
Parameters
Department
department name  ·  blank = all
Fiscal Period
Current · Q1 · Q2 · Q3 · Q4

PDF · Excel · HTML

Payment Date To

Invoice Aging Report Financial
Outstanding payables bucketed by aging interval: current (0–30 days), 31–60 days, 61–90 days and over 90 days. Critical for identifying overdue payables and managing supplier relationships before penalty clauses activate.
Parameters
Aging Bucket
All · Current · 31–60 d · 61–90 d · 90+ d
Supplier Filter
supplier name/code  ·  blank = all
Output Format
PDF · Excel · HTML
